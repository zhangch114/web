
# 🐶 DOGE 多因子追踪模型 · GitHub Pages 部署版

本项目为一个可直接部署在 GitHub Pages 上的前端多因子评分系统，支持链上数据、宏观因子、资金流分析、技术评分、策略建议与回测模块。

## 🚀 快速部署步骤

1. 将本仓库 fork 或 clone 到你的账号
2. 上传所有 HTML 文件（解压后）至仓库根目录
3. 打开仓库的 `Settings > Pages` 页面
4. 选择部署分支：`main`，部署目录：`/ (root)`
5. 等待几分钟即可通过 `https://你的用户名.github.io/仓库名/` 访问

## 📦 包含页面模块

- `DOGE_Dashboard_Final.html`：主导航页
- `DOGE_Score_Main_V2.html`：当前评分与雷达图
- `DOGE_Score_History_V3.html`：评分历史趋势
- `DOGE_Data_Fetch_V1.html`：模拟数据录入
- `DOGE_API_RealFetch_V2.html`：API 数据调用（CoinGlass / FRED）
- `DOGE_Strategy_Advisor_V1.html`：评分策略建议
- `DOGE_Backtest_Module_V1.html`：评分历史回测
- `DOGE_Settings_Module_V5.html`：设置中心
